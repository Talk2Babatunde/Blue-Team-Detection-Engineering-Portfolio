# DNS Threat Detection, Dashboarding & Automated Incident Response Using Splunk SIEM

A complete SOC-grade detection engineering project demonstrating end-to-end DNS threat monitoring, anomaly detection, alerting, and automated incident response using Splunk, Slack, and Jira. This case study replicates real enterprise workflows used in modern SOC teams.

## 🔥 Key Features
- Real-time DNS monitoring at scale
- Advanced detections (tunneling, beaconing, NXDOMAIN spikes, suspicious TLDs)
- Custom Splunk dashboards
- Slack webhook alerting
- Jira ticket auto-generation
- SOC investigation workflows with drilldowns
- MITRE ATT&CK technique mapping
- Evidence-based reporting
