# Executive Summary

This project showcases an end-to-end SOC detection pipeline built on Splunk SIEM to identify and respond to DNS-based threats. It includes ingestion, parsing, anomaly detection, real-time dashboards, alert automation, Slack notifications, and Jira ticket creation.

The goal is to replicate a professional SOC workflow:
- Detect → Alert → Investigate → Escalate → Document

The project demonstrates SOC Analyst, Detection Engineer, and Security Automation skills demanded in modern blue-team environments.
