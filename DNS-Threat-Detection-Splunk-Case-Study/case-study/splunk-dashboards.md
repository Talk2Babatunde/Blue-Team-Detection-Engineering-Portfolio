# Splunk DNS Monitoring & Threat Detection Dashboard

This dashboard includes:

- DNS volume over time
- Top queried domains
- Top source IPs
- NXDOMAIN anomalies
- Suspicious TLD queries
- Long domain (tunneling) detection
- High-frequency querying

Dashboard JSON located at:
splunk/dashboard-json/dns_monitoring_dashboard.json


All panels support interactive drilldowns for advanced investigation.
