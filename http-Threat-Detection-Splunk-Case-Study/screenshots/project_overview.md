This project demonstrates HTTP threat detection using Splunk dashboards, alerts, correlation rules, and incident response playbooks. The goal is to detect brute force attempts, directory scanning, suspicious user agents, and DoS activity using enriched HTTP logs.

Key capabilities:
- Full field extraction from raw logs
- Lookup-based threat enrichment
- Automated correlation across multiple indicators
- Dashboard visualizations for SOC monitoring
- Alerts mapped to IR playbooks
